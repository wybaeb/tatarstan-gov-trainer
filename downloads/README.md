# Учебные файлы

Файлы в этой папке содержат только сформированные для занятия примеры. Они не описывают фактические обращения, организации, территории или должностных лиц.

Обе книги Excel распространяются в формате XLSM и открываются с поддержкой макросов без промежуточного пересохранения. Для формул по умолчанию используются российские региональные настройки: точка с запятой между аргументами и запятая в дробной части. Международный вариант формул хранится отдельно и выбирается переключателем в тренажёре.
