# Практикум «Данные и ИИ в государственном управлении»

Статический тренажёр для очного занятия. Он не содержит ключей, реальных выгрузок, сведений об организациях, малых населённых пунктах, должностных лицах или фактических управленческих решениях.

В состав входят восемь последовательных заданий, лаборатория сезонных волн, лаборатория последовательного эксперимента и две учебные выгрузки на 12 324 строки для Excel/VBA и Google Apps Script.

## Использование на занятии

1. Участник открывает тренажёр по QR-коду.
2. Заполняет либо подставляет обучающие примеры.
3. Копирует сформированный запрос в разрешённый ИИ-сервис.
4. Вставляет ответ и получает карточку показателя, матрицу, формулу, проверку программного кода, карту контроля или паспорт пилота.

В текущей версии запросы намеренно не выполняются браузером: доступ к ИИ-сервису остаётся в защищённом контуре занятия. Это не требует передачи ключа в GitHub Pages.

## Локальная проверка

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Проверку запросов через GigaChat запускает только локальный разработчик, передавая ключ через переменную окружения; ключ в репозитории не хранится.

```bash
python3 scripts/browser_regression.py
GIGACHAT_AUTH_KEY=... GIGACHAT_MODEL=GigaChat python3 scripts/test_prompts_gigachat.py
```
