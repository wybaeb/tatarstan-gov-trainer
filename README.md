# Практикум «Данные и ИИ в государственном управлении»

Статический тренажёр для очного занятия. Он не содержит ключей, реальных выгрузок, сведений об организациях, малых населённых пунктах, должностных лицах или фактических управленческих решениях.

В состав входит единая последовательность из девяти шагов: паспорт показателя, сопоставимость периодов, разложение сезонности, проверка прогноза, последовательный эксперимент, автоматизация большого набора данных, классификация, матрица безопасности и защита ограниченного пилота. Для автоматизации подготовлены две учебные выгрузки на 12 324 строки для Excel/VBA и Google Apps Script. Книги Excel поставляются в формате XLSM. В режиме формул по умолчанию выбраны российские региональные настройки (`;` между аргументами и `,` в дробной части); переключатель позволяет получить международную запись.

Шаг безопасности начинается с шести жизненных рабочих ситуаций без готовой классификации. Участник описывает состав сведений, объём, способ передачи, цель и неизвестные условия, получает две строго структурированные таблицы и видит один из трёх учебных маршрутов: продолжить после обычной проверки, выполнить дополнительные условия либо остановиться и обратиться к уполномоченному специалисту. Валидатор принимает и новый табличный формат, и прежние ответы с маркированными списками.

## Использование на занятии

1. Участник открывает тренажёр по QR-коду.
2. Последовательно открывает данные, сезонные циклы, прогноз и накопление результатов эксперимента.
3. На шагах с ИИ заполняет поля, копирует сформированный запрос в разрешённый сервис и вставляет ответ.
4. Тренажёр проверяет структуру ответа и превращает JSON в паспорт показателя, матрицу маршрутизации, матрицу безопасности или презентацию защиты.
5. На шаге автоматизации участник скачивает Excel или CSV, получает программный код от ИИ и проверяет его по обязательным признакам.

В текущей версии запросы намеренно не выполняются браузером: доступ к ИИ-сервису остаётся в защищённом контуре занятия. Это не требует передачи ключа в GitHub Pages.

## Локальная проверка

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Проверку запросов через GigaChat запускает только локальный разработчик, передавая ключ через переменную окружения; ключ в репозитории не хранится.

```bash
python3 scripts/browser_regression.py
GIGACHAT_AUTH_KEY=... GIGACHAT_MODEL=GigaChat python3 scripts/test_prompts_gigachat.py
```
