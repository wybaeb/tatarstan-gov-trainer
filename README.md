# Практикум 13 октября: данные и ИИ в государственном управлении

Основная последовательность: 20 шагов, 13:20–15:35 и 15:45–18:10. Адреса `?section=...`; прежние `?step=1…9` работают. Учебный пароль `TATARSTAN13` показан на вводном слайде. Это заставка для организации занятия, не средство защиты закрытых данных.

Одна книга `downloads/praktikum_obrashcheniya.xlsm`: 20 454 обращения, две формулы и реальное скользящее 30-дневное окно с декабрьской предысторией. Контрольные значения рассчитаны независимо. Макросы требуют разрешённой среды Microsoft Excel; фактический запуск в Excel не выполнен на Linux.

Оригинальные визуальные тренажёры скопированы в labs, математические модули сохранены побайтно. Результаты анализа процесса и ИБ скачиваются и загружаются в два поля финального шага. Markdown/старый JSON становятся шестью слайдами; скачанный HTML листается без сети и печатается по слайду на горизонтальном листе.

Проверки: `scripts/test_course_browser.py`, `test_course_robustness.py`, `test_course_data.py`. Прогон точных запросов интерфейса на GigaChat — `test_course_gigachat.py`; ключ только в переменной окружения. Два повторных прогона обнаружили сохраняющиеся ошибки младшей модели в Excel/VBA: они отклоняются, доступны явные контрольные образцы. Валидатор VBA проверяет признаки алгоритма, а не заменяет компиляцию/исполнение. Обратная совместимость и небезопасная вставка HTML проверены браузером.

Отчёты разработки в reviews не публикуются в GitHub Pages: workflow копирует только учебные HTML/JS/CSS, labs, data и downloads. Госпромт ещё не подключён для сквозной проверки.

## Локальная проверка

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Проверку запросов через GigaChat запускает только локальный разработчик, передавая ключ через переменную окружения; ключ в репозитории не хранится.

```bash
python3 scripts/browser_regression.py
GIGACHAT_AUTH_KEY=... GIGACHAT_MODEL=GigaChat python3 scripts/test_prompts_gigachat.py
```
