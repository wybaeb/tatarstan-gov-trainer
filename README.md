# Практикум · Республика Татарстан

Текущая публикация содержит только зашифрованные учебные материалы. Пароль предоставляется участникам на занятии. Расшифровка выполняется в браузере; пароль в этой версии публикации не хранится.

Рабочие исходники и контрольные реализации не предназначены для открытой публикации. История прежних версий требует отдельного закрытия и не защищается шифрованием новых файлов.
