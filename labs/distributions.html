Как одно число меняет представление о данных?

Проведите мышью или пальцем по любому графику. Слева меняются значения наблюдений, справа — их распределение. Среднее, медиана и P90 пересчитываются сразу.

Среднее—Сумма значений, делённая на число наблюдений. Чувствительно к крайним значениям.
Медиана—Середина упорядоченного ряда. Не менее половины значений не превышают медиану.
P90 · 90-й процентиль—Уровень, ниже которого находится около 90% значений. Помогает увидеть длинное ожидание.

160 наблюдений · Значения в минутах · Диапазон 0–100

Рисуйте высоту столбиков: создайте один пик, два пика или хвост.

Гистограмма не хранит порядок наблюдений. Когда вы её меняете, слева строится один из возможных рядов; значения представлены серединами интервалов по 2,5 минуты. Число наблюдений может измениться.

Методика: среднее, медиана, P90 и два способа рисования

Среднее арифметическое: сумма всех значений / n. Медиана: центральное значение отсортированного ряда; для чётного n — среднее двух центральных. P90: 90-й процентиль, или 9-й дециль. Это показатель верхней части распределения, а не «более правильное среднее».

Как считается P90: линейная интерполяция, как в Excel PERCENTILE.INC и NumPy quantile(method="linear"). Для отсортированного ряда с индексами от 0: h = (n − 1) × 0,9. Если h дробное, берётся промежуточное значение соседей. При малом n доля значений ниже P90 может отличаться от 90%. При n = 0 показатели не определены.

Слева: каждый горизонтальный шаг — наблюдение. Перетаскивание меняет его значение; между движениями курсора линия интерполируется, поэтому быстрый жест не пропускает участки. При рисовании на пустом поле создаётся ряд из 160 начальных нулевых значений.

Справа: 40 равных интервалов по 2,5 минуты. Высота — число наблюдений, не вероятность. Правка гистограммы задаёт целочисленные частоты; их сумма определяет n. Размер набора ограничен 2000 наблюдениями. Для ряда используется воспроизводимая перестановка середин интервалов. Исходный порядок восстановить невозможно. После такой правки метрики отражают именно этот сгруппированный набор, а не скрытые значения внутри интервалов.

Заготовки: один пик, ряд с несколькими выбросами и смесь двух групп. Все данные учебные. Чтобы добавить выброс, поднимите несколько точек слева. Чтобы создать длинный хвост, добавьте немного наблюдений в правую часть гистограммы. Медиана и P90 тоже могут меняться: их устойчивость не абсолютна.
