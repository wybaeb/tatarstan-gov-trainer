# TAT-123
Ветка agent/TAT-123-defense. Две загрузки текстовых результатов, Markdown с контролем номеров/колонок, совместимость с шестью slides старого JSON. Используется существующий автономный HTML-слайдер: добавлены три варианта компоновки, содержание и строка проверки. Текст экранируется; встроенный предпросмотр изолирован iframe sandbox. Скачивание разрешено после валидации. Существующая матрица безопасности сохранена вместе с шестью сценариями; добавлена передача результата файлом. Синтаксис PASS; визуальный/печатный гейт выполняется при интеграции.
